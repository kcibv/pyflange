pyflange.io

Reading and writing flange fatigue cases in the PyFlange JSON format.

This module implements the PyFlange JSON case format, documented in detail in the JSON format reference. In particular it provides:

  • Loaders, that convert a JSON case file (or the equivalent dictionary) into PyFlange objects: load_fatiguecase, load_fatiguecase_sampler and the lower-level create_* functions.
  • Exporters, that convert PyFlange objects back into dictionaries in the same format (*_to_dict functions) and write dictionaries to JSON or Excel files (dict_to_json, dict_to_excel).
  • Monte Carlo helpers: sample_fatiguecase, that runs a simulation and returns a table of realizations, and create_realization, that rebuilds a single realization from that table.
Format versions

The current format version is 0.2.0 (FORMAT_VERSION). Files without a format_version field are assumed to be version 0.1.0 (the format used by the former Forrester tool) and are upgraded on the fly by upgrade_case, so they keep producing the same results.

Units

All values are expressed in SI units (m, N, Pa, rad), except where stated otherwise in the format reference.

Example 
from pyflange.io import load_fatiguecase, fatiguecase_to_dict, dict_to_json

fcase = load_fatiguecase("case.json")       # a BoltFatigueAnalysis object
print(fcase.damage, fcase.fatigue_life)

dict_to_json(fatiguecase_to_dict(fcase, verbose=True), "case-res.json")

DEFAULT_FLANGE_SEGMENT_TYPE = 'PolynomialLFlangeSegment' module-attribute

str: The flange segment type used when FlangeSegment.type is omitted (IEC 61400-6 AMD1 model).

FLANGE_SEGMENT_TYPES = ('PolynomialLFlangeSegment', 'PolynomialLFlangeSegmentED2') module-attribute

tuple: The flange segment types supported by the JSON format.

FORMAT_VERSION = '0.2.0' module-attribute

str: The version of the JSON format written by this module.

LEGACY_DS_REF_MEAN = 62000000.0 module-attribute

float: Mean fatigue reference stress range implicitly used by format 0.1.0 samplers, in Pa. Format 0.1.0 files get it assigned when upgraded.

SAMPLE_COLUMNS = ['BoltPreload', 'GapShapeFactor', 'TiltAngle', 'GapAngle', 'GapHeight', 'FatigueClass', 'MomentRangeCoefficient', 'Damage', 'AllowableDamage', 'FatigueLife', 'SMF', 'Utilization'] module-attribute

list: The columns of the table returned by sample_fatiguecase.

SUPPORTED_FORMAT_VERSIONS = ('0.1.0', '0.2.0') module-attribute

tuple: The JSON format versions that this module can read.

create_fatiguecase_sampler(fseg, markov_matrix, **params)

Creates a sampler of random fatigue cases.

The random flange segments are of the same type as fseg and share its deterministic parameters. Their shell stiffness is always interpolated from the FEA data (see pyflange.flangesegments.shell_stiffness) as a function of the random gap angle.

Parameters:
  • fseg (PolynomialLFlangeSegment) –

    The base flange segment object.

  • markov_matrix (MarkovMatrix) –

    The base Markov matrix object.

  • **params –

    Statistical parameters (Stats section, current format version), for preload, plastic loss, DFT, gap, tilt, load range factor, fatigue class factor, allowable damage and stress multiplication factor.
Returns:
  • Generator –

    A generator that yields randomized BoltFatigueAnalysis objects.
Raises:
  • ValueError –

    If an unsupported distribution type is provided for any parameter.

  • KeyError –

    If a required parameter is missing.

    If the curve type is not supported.

create_flangesegment(**params)

Creates a flange segment from a dictionary of parameters.

Given a dictionary containing the parameters for a flange segment object in the PyFlange JSON format (FlangeSegment section), returns the corresponding flange segment. Only L-flange segments are supported.

The bolt preload is given either as preload_ratio (fraction of the bolt tensile yield force, As * fy) or as an absolute force Fv, but not both.

Parameters:
  • **params –

    Flange segment parameters. Expected keys are 'a', 'b', 's', 't', 'R', 'central_angle', 'Zg', 'bolt', 'preload_ratio' or 'Fv', 'Do', 'washer', 'nut', 'gap', 'tilt_angle', 'E', 'G', 's_ratio', 'r', 'k_shell', 'PPL', 'DFT', 'settlement_factor' and, optionally, 'type' (default DEFAULT_FLANGE_SEGMENT_TYPE). Other keys are ignored.
Returns:
  • PolynomialLFlangeSegment –

    The flange segment object (possibly a PolynomialLFlangeSegmentED2).
Raises:
  • ValueError –

    If an unsupported type is provided, or if the preload is not specified exactly once.

dict_to_excel(d, file_path)

Writes a dictionary to an Excel file.

This utility function takes a dictionary and an Excel file name as inputs, flattens the dictionary into a list of chained-key-value pairs, and writes it to an Excel file in a two-column table, where the first column contains the keys and the second column contains the corresponding values. Each value cell is also given an Excel name equal to its key, so that it can be referenced by name from other workbooks.

Example

Given the following dictionary: d = { "a": 10, "b": { "c": 20, "d": 30 } }

This function will write it to Excel in the following format: | KEY | VALUE | |-----|-------| | a | 10 | | b.c | 20 | | b.d | 30 |

Parameters:
  • d (dict) –

    The dictionary to be written.

  • file_path (str) –

    The path to the Excel file to be created.

sample_fatiguecase(data, size, seed=None, progress=None)

Runs a Monte Carlo simulation of a fatigue case.

Parameters:
  • data (dict) –

    A case dictionary, including the Stats section.

  • size (int) –

    Number of realizations to generate.

  • seed (int, default: None ) –

    Seed of the random number generator. If given, the numpy global random generator is re-seeded, so that the simulation is reproducible. If omitted, the current random state is used.

  • progress (callable, default: None ) –

    A function called as progress(i) after the generation of the i-th realization (1-based).
Returns:
  • –

    pandas.DataFrame: A table with one row per realization and the columns listed in SAMPLE_COLUMNS. Lengths are in m, forces in N, angles in rad, stresses in Pa, fatigue life in the time units of the Markov matrix duration. FatigueClass is the knee-point stress range of the sampled bolt S-N curve and MomentRangeCoefficient the factor applied to the load ranges.

upgrade_case(data)

Converts a case dictionary to the current format version.

The input dictionary is not modified: a converted copy is returned. Upgrading a version 0.1.0 case:

  • sets format_version to the current version;
  • adds DS_ref_mean = 62 MPa to Stats.FatigueClassFactor, if the Stats section is present, which is the value implicitly used by the version 0.1.0 Monte Carlo sampler.
Parameters:
  • data (dict) –

    A case dictionary in any supported format version.
Returns:
  • dict –

    An equivalent case dictionary in the current format version.
Raises:
  • ValueError –

    If the format version is not supported.
