    pyflange.flangesegments ¶

    Mechanical models of single-bolt flange segments.

    This module contains FlangeSegment classes, which model the mechanical behavior of a flange sector containing one bolt only. The module provides:

    • Gap: description of the imperfection gap between two flange faces.
    • FlangeSegment: abstract base class defining the transfer-function interface (bolt axial force and bolt bending moment as functions of the shell pull force).
    • PolynomialFlangeSegment: abstract base class implementing the polynomial transfer functions of refs. [1] and [2].
    • PolynomialLFlangeSegment and PolynomialLFlangeSegmentED2: polynomial L-flange segment models (the latter implementing the modifications expected in IEC 61400-6 ED2).
    • PolynomialTFlangeSegment and PolynomialTFlangeSegmentED2: polynomial T-flange segment models (the latter implementing the modifications expected in IEC 61400-6 ED2).
    • bolt_markov_matrix: conversion of a flange bending-moment Markov matrix into a bolt stress Markov matrix, via the segment transfer functions.
    • shell_stiffness: shell stiffness interpolated from tabulated FEA results.

    The only types of FlangeSegment currently available are an L-Flange segment and a T-Flange segment, implementing a polynomial relation between tower shell force and bolt force / bolt moment. Nonetheless, this module has been structured to be easily extensible with other types of FlangeSegment model, such as Multilinear (Petersen) L-Flanges, Multilinear T-Flanges, etc.

    Units

    All parameters must be supplied in a consistent system of units, e.g. meters for lengths, newtons for forces and pascals for stresses. Angles are expressed in radians.

    Example

    The following example creates an L-flange segment and evaluates the bolt axial force for a given shell pull force.

    from math import pi
from pyflange.bolts import StandardMetricBolt, RoundNut
from pyflange.flangesegments import Gap, PolynomialLFlangeSegment

fseg = PolynomialLFlangeSegment(
    a=0.150, b=0.122, s=0.054, t=0.172, R=4.0,
    central_angle=2*pi/156,
    Zg=-115e3,                              # dead weight per bolt (compression)
    bolt=StandardMetricBolt("M80", "10.9", shank_length=0.160, stud=True),
    Fv=2.9e6,                               # bolt preload
    Do=0.086, washer=None, nut=RoundNut("M80"),
    gap=Gap(height=0.002, angle=pi/6))

Fs = fseg.bolt_axial_force(500e3)           # bolt force for a shell pull of 500 kN

    PolynomialFlangeSegment ¶

    Bases: FlangeSegment

    A generic FlangeSegment with polynomial transfer functions.

    This class implements a polynomial relation between tower shell force Z and bolt axial force Fs or bolt bending moment Ms. It is not meant to be instantiated directly but to be subclassed.

    The polynomial transfer functions are defined by 4 reference points:

    • P1: Flange segment at rest.
    • P2: Flange segment at ultimate tensile limit state.
    • P3: Flange segment in small tensile deformation.
    • P4: Gap closure state.

    Child classes must provide the coordinates of these points (shell force, bolt force and bolt moment) through the abstract properties of this class. The transfer functions are a quadratic polynomial through P1, P2 and P3 in the tensile domain (above the shell force at rest), a quadratic polynomial between P4 and P1 in the compressive domain, and a constant below P4. Child classes may override the tensile polynomials when the reference defines them differently (e.g. the cubic bolt moment of T-flanges).

    bolt_preload cached property ¶

    bolt_preload

    float: Bolt preload after settlement and plastic losses.

    failure_mode ¶

    failure_mode(fy_sh, fy_fl, gamma_0=1.1)

    Determines the failure mode of the flange.

    The ultimate shell force is evaluated for each of the failure modes A, B, D and E of ref. [2], and the governing mode is the one with the lowest ultimate shell force.

    Parameters:

    • fy_sh (float) –

      Yield stress of the shell material.

    • fy_fl (float) –

      Yield stress of the flange material.

    • gamma_0 (float, default: 1.1 ) –

      Material factor. Defaults to 1.1.

    Returns:

    • tuple –

      A tuple containing:

      • str: The failure mode ("A", "B", "D", or "E").
      • list: A list of the shell force limits for each failure mode [Zu_A, Zu_B, Zu_D, Zu_E].

    A T-Flange implementation of a PolynomialFlangeSegment.

    This class models a T-flange segment using the polynomial model from ref. [1] and [2]. It defines the reference points for the polynomial functions inherited from the parent class. The segment contains a pair of bolts, one on each side of the shell.

    The transfer functions are available through the bolt_axial_force and bolt_bending_moment methods, which accept either a scalar or a NumPy array of shell pull forces. Differently from the L-flange, the bolt bending moment in the tensile domain is a cubic polynomial (ref. [2], eq. G.61).

    failure_mode ¶

    failure_mode(fy_sh, fy_fl, gamma_0=1.1)

    Determines the failure mode of the flange.

    The ultimate shell force is evaluated for each of the failure modes A, B, D and E of ref. [2] (eqs. G.24 to G.29), and the governing mode is the one with the lowest ultimate shell force.

    Parameters:

    • fy_fl (float) –

      Yield stress of the flange material.

    • gamma_0 (float, default: 1.1 ) –

      Material factor. Defaults to 1.1.

    Returns:

    • tuple –

      A tuple containing:

      • str: The failure mode ("A", "B", "D", or "E").
      • tuple: The shell force limits for each failure mode (Zu_A, Zu_B, Zu_D, Zu_E).

    A T-Flange segment modeled as it will be modified in IEC 61400-6 ED2.

    This class has the same parameters and interface as PolynomialTFlangeSegment, but it replaces the gap stiffness with the formulation that will be introduced in IEC 61400-6 ED2 (ref. [5], sections 9.3.3 and 9.7, change #2). The other ED2 changes of ref. [5], section 9.7 (torsional correction factor and a*) only concern L-flanges.

    bolt_markov_matrix ¶

    bolt_markov_matrix(fseg, flange_markov_matrix, bending_factor=0.0, macro_geometric_factor=1.0, mean_factor=1.0, range_factor=1.0, SMF=1.0)

    Evaluates the bolt Markov matrix from the shell Markov matrix.

    The flange bending moment ranges and means are converted into shell pull forces acting on the flange segment, and then into minimum and maximum bolt stresses through the transfer functions of the flange segment. The bolt stress is the sum of the axial stress and of the bending stress scaled by bending_factor, evaluated on the bolt thread cross-section, according to ref. [2], section 6.7.5.4, eq. (42).

    The flange bending moment M is converted into the segment shell force as Z = M / W * A_seg (ref. [2], eq. G.33), where W is the section modulus of the tower shell, evaluated at the shell mid-surface, and A_seg the shell cross-section area of the segment.

    Parameters:

    • fseg (PolynomialFlangeSegment) –

      The flange segment containing the transfer functions. WARNING: Currently only works with PolynomialFlangeSegments.

    • flange_markov_matrix (MarkovMatrix) –

      The Markov matrix of bending moments on the flange.

    • bending_factor (float, default: 0.0 ) –

      Factor for the bending portion of the total stress range (kappa_b of ref. [2], eq. (43)). Defaults to 0.0 (axial stress only).

    • macro_geometric_factor (float, default: 1.0 ) –

      Factor for macro geometric influences (the SCF of ref. [2], section 6.7.5.3), affecting dead weight, mean, and range values. If omitted, it defaults to 1.0.

    • mean_factor (float, default: 1.0 ) –

      Factor for the mean values of the tower's bending moments. If omitted, it defaults to 1.0.

    • range_factor (float, default: 1.0 ) –

      Factor for the range of the tower's bending moments. If omitted, it defaults to 1.0.

    • SMF (float, default: 1.0 ) –

      Stress Multiplication Factor to be applied to bolt Markov matrix stress ranges. If omitted, it defaults to 1.0.

    Returns:

    • MarkovMatrix –

      The bolt's Markov matrix representing the stress history. Its cycles and duration are the same as the flange Markov matrix.

    shell_stiffness ¶

    shell_stiffness(shell_radius, shell_thickness, gap_angle)

    Calculates the axial stiffness of a flange-segment shell via interpolation.

    This function interpolates shell stiffness from a dataset of 2160 FEA results, covering 8 diameters (3 m to 10 m), 15 shell thicknesses (10 mm to 150 mm) and 18 gap angles (10° to 180°). This is the database of pre-computed stiffness values described in ref. [5], section 9.3.1, as an alternative to the simplified formula of ref. [2], eqs. G.43 and G.44. Values outside the range covered by the dataset are not extrapolated, and nan is returned instead.

    Example 
    from math import pi
from pyflange.flangesegments import shell_stiffness

k_shell = shell_stiffness(4.0, 0.054, pi/6)   # R = 4 m, s = 54 mm, 30° gap

    Parameters:

    • shell_radius (float) –

      Outer radius of the shell.

    • shell_thickness (float) –

      Thickness of the shell.

    • gap_angle (float) –

      Angular length of the flange gap in radians.

    Returns:

    • float –

      The interpolated shell stiffness (K_sh), or nan if the arguments are outside the dataset range.
